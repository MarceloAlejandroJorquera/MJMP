# Changelog

## v1

Initial public binary release.

- Portable single-executable x64 Windows build (`MJMPv1.exe`).
- Static media codec/demux stack; no external codec pack is required.
- D3D11 compatibility renderer selected by default on a fresh configuration.
- Optional D3D12 renderer and selectable 8-bit, 10-bit, and 16-bit-float output precision.
- Subtitle styling and preview controls.
- Tray playback preview and transport controls.
- Configurable playback, visibility, and hotkeys.
- Built-in GitHub release notification support with an option to disable version checks.
